# better-render for Claude Code

Formulas as images and aligned CJK tables in Claude Code's replies, drawn by the
[pi-better-render](https://github.com/JeffeyChou/pi-better-render) renderer. Display only: the
stored reply, the transcript and the model's context keep the original Markdown.

## Install

At the Claude Code prompt (Claude Code 2.1.330 or later):

```
/plugin install better-render --marketplace JeffeyChou/pi-better-render
```

From a shell:

```sh
claude plugin marketplace add JeffeyChou/pi-better-render
claude plugin install better-render@pi-better-render
```

Then start a new session, or run `/reload-plugins`.

## What it does

- Text blocks that contain `$…$`, `\(…\)`, `$$…$$`, `\[…\]`, AMS environments or tables are drawn by
  the shared renderer; everything else stays with Claude Code's own Markdown.
- Formulas are MathJax 4, rasterized by resvg-wasm and shown with Claude Code's `Image` element in
  Ghostty and kitty. In other terminals, and inside tmux, they are a Unicode approximation.
- A block is drawn once it is complete; formulas do not appear while it streams.
- `/better-render` reports the terminal, the math engine and the formula color in use.

Options (`/plugin` → better-render → configure): `images` (`auto`, `on`, `off`), `cellAspect`
(cell height / width of your terminal font, default 2.1) and `formulaColor` (`#rrggbb`).

`hooks/register.tsx` is the plugin. `lib/` is generated by `tools/build-claude.mjs` in the
